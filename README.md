# 6 Minute English リスニング＆単語ノート (PWA)

BBC Learning English「6 Minute English」専用のリスニング＆AI単語ノートWebアプリです。
iPhoneのSafariから「ホーム画面に追加」することで、全画面のネイティブアプリ風PWAとして利用できます。

## 主な機能

1. **RSSからのエピソード＆オリジナル音声自動取得 (`GET /api/episodes`)**
   - BBC公式RSSフィード（`https://podcasts.files.bbci.co.uk/p02pc9tn.rss`）から最新20件のエピソード情報とMP3 URLを自動取得します。
   - 標準の `<audio>` 要素と Media Session API に対応し、iPhoneのロック画面やコントロールセンターからも操作できます。

2. **AI文字起こしと再生位置の同期 (`POST /api/transcribe`)**
   - Gemini API (`gemini-3.8-flash`) を用いて、MP3音声からタイムスタンプ付き文字起こし（`segments`）と重要イディオム一覧（`idioms`）を抽出します。
   - 生成された文字起こしはブラウザの `localStorage` にキャッシュされ、2回目以降はAPIを呼ばずに即座に表示されます。
   - 再生位置に応じたセグメントのハイライト、自動追従スクロール（ON/OFF切替）、タイムスタンプタップによるシーク再生に対応しています。

3. **単語・イディオムのタップ解説 (`POST /api/define`)**
   - イディオムは破線下線付きの1つのまとまりとして、その他の語は単語単位でタップ可能です。
   - タップすると下部シートが開き、前後の文脈を踏まえた日本語訳・品詞・発音記号・ニュアンス解説・実用的な例文をAIが生成します（結果はメモリおよび `localStorage` にキャッシュ）。
   - Web Speech API (`en-GB`) によるイギリス英語発音再生ボタンを搭載しています。

4. **チェックマークによる手動記録＆単語ノート**
   - ボトムシート下部のチェックマークボタン（「単語ノートに記録」）を押した語句のみ `localStorage` の単語ノートに保存され、文字起こし本文中でもハイライト表示されます。
   - 「単語ノート」タブでは、キーワード検索、フィルター（すべて／未習得／覚えた）、「意味を隠す」復習モード（タップでぼかし解除）、登場エピソード＆秒数へジャンプして再生するボタン、削除ボタンを利用できます。

## セットアップ手順

### 1. 環境変数の設定

プロジェクトルートに `.env.local` を作成し、Google AI Studio で取得した Gemini API キーを設定してください。

```env
GEMINI_API_KEY=あなたのGEMINI_API_KEY
```

### 2. パッケージのインストールと起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

### 3. iPhoneのSafariでPWAとして使う場合

1. 同一Wi-Fi内のiPhone Safariから開発サーバー（またはデプロイ先URL）を開きます。
2. Safari下部の「共有」アイコンから **「ホーム画面に追加」** を選択します。
3. ホーム画面に追加されたアイコンから起動すると、アドレスバーのない全画面PWAとして動作します。
